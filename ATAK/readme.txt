Данное руководство содержит пошаговый алгоритм развертывания сервера командной синхронизации FreeTAKServer (FTS) на виртуальном выделенном сервере (VDS/VPS) под управлением Linux.

Шаг 1: Подключение к удаленному серверу по протоколу SSH
Для настройки конфигурации необходимо установить защищенное терминальное соединение с VDS. На локальном компьютере (ОС Windows) запустите интерфейс командной строки: нажмите Win + R, введите cmd и нажмите Enter. Инициируйте SSH-сессию с правами суперпользователя root:
              ssh root@IP_АДРЕС_ВАШЕГО_СЕРВЕРА
При первичном подключении к хосту подтвердите подлинность ключа: введите yes и нажмите Enter. Аутентифицируйте сессию, вставив пароль администратора (из личного кабинета хостинга) через клик правой кнопкой мыши или комбинацию Shift + Insert, после чего нажмите Enter. Примечание: в целях безопасности вводимые символы пароля в консоли Linux не отображаются. Успешная авторизация подтверждается изменением строки приглашения на root@имя_хоста:~#.

Шаг 2: Установка Docker и плагина Compose
Для изоляции и управления компонентами сервера используется контейнеризация. Выполните в терминале следующие команды:
Обновите индексы репозиториев операционной системы:
              apt update
Установите среду выполнения Docker и инструмент сборки контейнеров:
              install -y docker.io docker-compose-v2
Внимание: при появлении диалогового окна настроек «Automatically restart Docker daemon?» переключите фокус клавишей Tab на вариант <Yes> и нажмите Enter.

Шаг 3: Конфигурация манифеста Docker Compose
Для автоматизации развертывания FreeTAKServer необходимо декларативно описать структуру контейнеров и сетевых правил. Создайте и откройте конфигурационный файл во встроенном текстовом редакторе nano:
              nano docker-compose.yml
Скопируйте и вставьте (клик правой кнопкой мыши в консоли) следующий YAML-код:

            # Секция "services" запускает список нужных нам программ (контейнеров)
              services:
            # Это внутреннее имя нашей программы внутри Docker (название для системы)
              freetakserver:
            # Откуда скачивать программу. Качаем свежий FreeTAKServer с официального GitHub
              image: ghcr.io/freetakteam/freetakserver:latest
            # Как контейнер будет красиво называться в списке запущенных процессов вашего ПК
              container_name: freetakserver
            # Секция "ports" открывает двери (порты) из контейнера на ваш реальный компьютер
              ports:
            # Открываем порт 8080 для веб-меню и внутренних системных запросов (API)
              - "8080:8080"
            # Открываем порт 8443 для того же веб-меню, но с защитой шифрования (SSL)
              - "8443:8443"
            # ГЛАВНЫЙ ПОРТ: Сюда в приложении ATAK на телефоне подключаемся без шифрования
              - "8087:8087"
            # ВТОРОЙ ПОРТ: Сюда подключаемся в ATAK, если внутри приложения включили SSL-защиту
               - "8089:8089"
            # Секция "environment" задает внутренние настройки для самого сервера
              environment:
            # FTS_CONNECTION_MESSAGE — команда серверу заменить дефолтное приветствие на ваш текст
              - FTS_CONNECTION_MESSAGE="Добро пожаловать в систему VALHALLA, Оператор!"
            # Секция "volumes" привязывает виртуальную папку контейнера к жесткому диску вашего ПК
              volumes:
            # fts-data (папка на ПК) связывается с /app/FreeTAKServer (папка внутри контейнера)
            # Это нужно, чтобы при перезапуске сервера ваши карты и SSL-сертификаты не стирались
              - fts-data:/app/FreeTAKServer
            # Если сервер заглючит и упадет или вы перезагрузите компьютер — Docker включит его сам
              restart: always
            # Секция "volumes" в самом низу регистрирует виртуальный диск в системе Docker
              volumes:
            # Даем системе команду: "Создай на жестком диске постоянное место с именем fts-data"
              fts-data:

Сохраните изменения в файле: нажмите Ctrl + O, затем подтвердите имя файла клавишей Enter. Закройте текстовый редактор: нажмите Ctrl + X.

Шаг 4: Запуск и верификация контейнераИнициализируйте развертывание инфраструктуры в фоновом режиме (демоне):
            docker compose up -d
Система начнет загрузку слоев Docker-образа. Дождитесь завершения процесса, пока статус целевого контейнера не сменится на Started.Проверьте текущий статус активности запущенных контейнеров:
            docker ps
Убедитесь, что в столбце STATUS для контейнера freetakserver указано значение Up (работает).

Диагностика и мониторинг логовДля отслеживания сетевой активности клиентов, анализа трафика и разбора ошибок используйте вывод потока системных сообщений:
            docker logs -f freetakserver
Для прерывания вывода логов и возврата к управлению терминалом нажмите сочетание клавиш Ctrl + C.
